Backend endpoint for frontend

Method:
GET

Path:
/api/admin/rooms/{room_id}/courses

Example:
GET /api/admin/rooms/486f969a-0a2b-46c1-8156-cbb7ff2468ef/courses

Auth:
Bearer token is required.
Allowed roles are staff and admin.

Headers:
Authorization: Bearer <token>


Response shape

The endpoint returns an array of courses.

Example response:

Backend behavior

1. The frontend sends the selected room_id in the URL.

2. The backend verifies the user is staff or admin.

3. If the user is admin, the backend allows reading courses for any room.

4. If the user is staff, the backend checks that the selected room_id is inside the staff user's assigned_rooms array.

5. If the staff user is not assigned to that room, the backend returns 403.

6. If the room does not exist, the backend returns 404.

7. If the room exists but has no courses, the backend returns an empty array.

8. If courses exist, the backend returns them sorted by course_code.

The frontend needs to:

1. Add API helper:

export const getCoursesByRoom = async (roomId: string, token: string): Promise<Course[]> => {
  return request<Course[]>(`/api/admin/rooms/${roomId}/courses`, token);
};

2. Store courses in state:

const [courses, setCourses] = useState<Course[]>([]);

3. Fetch courses whenever selectedRoomId changes:

useEffect(() => {
  if (!selectedRoomId || !token) {
    setCourses([]);
    return;
  }

  getCoursesByRoom(selectedRoomId, token)
    .then(setCourses)
    .catch(() => setCourses([]));
}, [selectedRoomId, token]);

4. Pass the fetched courses instead of an empty array:
